# HBIMS-APP

This React Native example shows how to localise the onboarding screen based on the language selected by the user.

## Getting started

1. Install dependencies
   ```bash
   npm install
   ```
2. Start the Expo dev server
   ```bash
   npm start
   ```
3. Open the app on a simulator or device. Select a language tile and the welcome text plus continue button will automatically switch to the translated content.

The localisation logic is implemented without any native modules so it runs on Android, iOS, and web (through Expo) without additional setup.
